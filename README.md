# Rohit Pedagadi Portfolio

React portfolio built with Vite. Includes reusable section components, an interactive API flow illustration, contact links, and the resume PDF.

## Run locally

pnpm install
pnpm dev

## Production build

pnpm build
pnpm preview

Source: src/main.jsx and src/style.css. Resume: public/resume.pdf. Production files: dist/.

GSAP powers entrance and scroll animations. Clickable focus cards describe the work; experience details expand on demand. Motion respects reduced-motion preferences. Contact links open email or LinkedIn. The existing Sites project identity is retained in .openai/hosting.json. Online publication has not completed.
